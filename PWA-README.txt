НИКА МОИСЕЕВА — установка веб-приложения

1. Замените существующий HTML сайта содержимым Nika-Catalog.html. Если на GitHub Pages главная страница называется index.html, сохраните обновлённый HTML именно под именем index.html.
2. В ту же папку репозитория загрузите manifest.webmanifest, sw.js и четыре PNG-иконки. Существующие фотографии оставьте на месте.
3. Дождитесь публикации GitHub Pages и откройте сайт по HTTPS.

iPhone: Safari → Поделиться → На экран «Домой» → включить «Открыть как веб-приложение», если этот переключатель доступен → Добавить.
Android: Chrome → меню ⋮ → Установить приложение / Добавить на главный экран.

После первого онлайн-посещения основной каталог и поиск доступны без сети, если браузер сохранил кэш. Внешние видео, стримы и платежи требуют подключения.

Если приложение добавлялось до этого обновления, удалите ярлык с домашнего экрана и добавьте заново, чтобы обновить иконку и параметры запуска.
