РАЗДЕЛ «СИГНЫ» — САЙТ НИКИ МОИСЕЕВОЙ

1. Распакуйте архив. В корень репозитория Clubnika загрузите:
   signs.html, папку signs и обновлённые index.html, about.html, songs.html.
   Остальные существующие файлы сайта оставьте без изменений.
   Папка tools и этот README предназначены для локальной работы.

2. Для просмотра используйте адрес /signs.html. В меню главной,
   страницы «Обо мне» и каталога появился пункт «Сигны».

3. Обновление коллекции. Нужен установленный FFmpeg (в PATH).
   Откройте PowerShell в распакованной папке и выполните:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Update-Signs.ps1

   Другую папку-источник можно указать через -Source:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\Update-Signs.ps1 -Source "D:\Downloads\Telegram Desktop\Сигны"

   Скрипт копирует оригиналы, создаёт JPEG/MP4 не более 640 пикселей
   по длинной стороне, генерирует постеры видео и список signs/data.js.
   Уже обработанные файлы повторно не кодируются. Оригиналы не меняются.
   Удалённые из источника позиции исчезают из списка, но старые файлы
   остаются в папке signs, чтобы случайно не потерять оригиналы.
   После обновления загрузите изменённую папку signs на GitHub.

4. Полноразмерные файлы доступны посетителям напрямую. Перед публикацией
   убедитесь, что все фотографии и видео предназначены для общего доступа.
